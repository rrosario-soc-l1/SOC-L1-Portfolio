Home Lab: Arquitectura y Proyectos

He diseñado e implementado un ecosistema de seguridad en un entorno virtualizado (VirtualBox) para prácticas de Purple Team (Ataque y Defensa).

*   **Servidor SIEM (Debian):** Wazuh Manager + Indexer + Dashboard.
*   **Endpoint (Ubuntu):** Wazuh Agent desplegado para telemetría de seguridad (Syscheck, Rootcheck, Logs).
*   **Atacante (Kali Linux):** Utilizado para simulación de vectores de ataque (Fuerza Bruta, Escaneos).

Proyecto Destacado: Detección y Respuesta a Fuerza Bruta SSH
*   **Simulación:** Ejecución de ataque de diccionario con `Hydra` contra el endpoint Ubuntu.
*   **Detección:** Identificación de alertas de múltiples fallos de autenticación (Regla 5710/5712 de Wazuh) y correlación de eventos.
*   **Triaje:** Análisis en el Dashboard para confirmar o descartar un acceso exitoso (MITRE ATT&CK: T1110 - Brute Force).
*   **Contención:** Bloqueo de la IP atacante en el firewall del endpoint (`ufw deny from <IP>`) y documentación del incidente para escalado.
